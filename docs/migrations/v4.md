# Upgrading from ARCitISA 3.x to 4.0

ARCitISA 4.0 comes with new installers and moves your settings to a new folder. Most of this happens on its own. This page says what changes and what you may have to do.

## Before you install

Close all ARCitISA windows, including those of older versions.

## Windows

The 4.0 setup finds an installed 3.x version, asks whether to remove it, and removes it when you say Yes. Your settings and signed-in accounts are kept, and afterwards Settings > Apps lists only ARCitISA 4.0. If you say No, the setup closes without installing anything. If you had several 3.x versions installed side by side (for example 3.4.0-rc.2 and 3.4.0), the setup removes all of them after one question.

If the old version cannot be removed, the setup tells you why and stops. Close all ARCitISA windows and run the setup again.

The setup only looks for 3.x versions of the Windows user who runs it. Other users on the same computer remove their own 3.x installation.

For administrators: a silent install (`ARCitISA-Setup-<version>-x64.exe /S`) does not remove 3.x. It stops with exit code 1 when 3.x is installed for that user. Remove 3.x first, in Settings > Apps or with its uninstaller, or run the setup interactively once.

## Linux

- deb and rpm: the new `arcitisa` package replaces the `swate` package of versions up to 3.4.0-rc.2. apt and dnf list `swate` as removed before you confirm. Versions that were already called `arcitisa` are updated normally.
- pacman: a normal update with `sudo pacman -U`.
- AppImage and zip: delete the old file or folder yourself.

## macOS

Drag ARCitISA from the dmg to Applications and let Finder replace the old app. ARCitISA 4.0 has a new app identifier, so macOS may ask again for permissions you gave to 3.x.

## Your settings

ARCitISA 3.x kept your settings, signed-in accounts and the list of recent ARCs in a folder called `Swate`. On its first start, ARCitISA 4.0 moves this folder to a folder called `ARCitISA`:

| | 3.x | 4.0 |
| --- | --- | --- |
| Windows | `%AppData%\Swate` | `%AppData%\ARCitISA` |
| macOS | `~/Library/Application Support/Swate` | `~/Library/Application Support/ARCitISA` |
| Linux | `~/.config/Swate` | `~/.config/ARCitISA` |

The folder moves as a whole, so you stay signed in. Your ARCs are not in this folder and are not touched.

If the move fails, ARCitISA shows both folders and the reason, and closes. Close all ARCitISA windows, including older versions, and start ARCitISA again.

If you go back to 3.x after using 4.0, 3.x starts with empty settings, because it looks for the `Swate` folder. When you start 4.0 again, it keeps its `ARCitISA` folder and deletes the `Swate` folder that 3.x created in the meantime.

## What resets once

These were stored under names from the time ARCitISA was called Swate. 4.0 uses new names and starts with the defaults:

- the theme, the term search settings and other preferences kept in the app's browser storage, such as panel sizes;
- in some cases, which signed-in account is selected (you stay signed in, choose the account again);
- in the web and Excel versions, the table history and the search configuration.

Copying cells from 3.x and pasting them into 4.0, or the other way round, pastes plain text instead of cells.

## Leftovers in your ARCs

If an import or a save in 3.x was interrupted, it may have left a hidden folder named `.swate-import-` followed by 32 characters, or a file named `.swate-save-` followed by 32 characters and `.tmp`. ARCitISA 3.x hid them. 4.0 shows them as normal files and folders. You can delete them.

## Excel add-in

The add-in manifest of 4.0 opens ARCitISA with a new parameter. Add-ins installed from an older manifest keep working.
